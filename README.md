## Проєкти

### Економічна безпека Кіпру

Екзаменаційний вебсайт «Економічна безпека країни» — аналіз економічної безпеки Республіки Кіпр за 2020–2025 роки.

🌐 **Сайт:** https://kossstya.github.io/Development/cyprus-economic-security/

**Зміст:**
- `index.html` — інформація про автора;
- `analysis.html` — аналіз: картки ключових показників, таблиця індикаторів із пороговими значеннями, інтерактивний графік динаміки, інтегральна оцінка, комбінований графік «державний борг + сальдо бюджету», безпечні та небезпечні тенденції, основні загрози, аналітичний висновок і джерела.

**Технології:** HTML5, CSS3, JavaScript, [Chart.js](https://www.chartjs.org/).

**Джерела даних:** Eurostat, Central Bank of Cyprus, CYSTAT.
